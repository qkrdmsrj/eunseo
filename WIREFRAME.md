# Creator Rate Calculator 와이어프레임

- 문서 버전: v1.0
- 기준 문서: [PRD.md](PRD.md)
- 단계: 저충실도 와이어프레임
- 대상: 반응형 웹앱

## 1. 화면 구조

```text
[01 시작 화면]
       |
       v
[02 계정 지표] ---> [입력 오류/경고 상태]
       |
       v
[03 캠페인 조건]
       |
       v
[04 계산 결과] ---> [05 시나리오 비교]
       |
       +-----------> 공유 / PNG·PDF 다운로드 / 다시 계산
```

## 3. 화면 01: 시작 화면

### 목적

사용자가 계산 목적을 이해하고 즉시 계산을 시작하도록 한다. 로그인이나 플랫폼 연동을 요구하지 않는다.

### 데스크톱

```text
+--------------------------------------------------------------------------+
| CREATOR RATE                                              KRW v  도움말 |
+--------------------------------------------------------------------------+
|                                                                          |
|                 나의 광고단가, 근거 있게 계산하기                       |
|      팔로워 수뿐 아니라 참여도와 캠페인 조건을 반영한 예상 단가          |
|                                                                          |
|                 +----------------------------+                           |
|                 |        계산 시작하기       |                           |
|                 +----------------------------+                           |
|                                                                          |
|        인플루언서                         브랜드/대행사                   |
|        내 협찬 단가 확인                  캠페인 예산 산정                |
|                                                                          |
|  참고용 추정치입니다. 실제 계약가는 콘텐츠 품질과 협상 조건에 따라       |
|  달라질 수 있습니다.                                                      |
+--------------------------------------------------------------------------+
```

### 동작

- `계산 시작하기` 클릭: 화면 02로 이동
- `KRW` 선택: 통화 메뉴 표시
- 카드 선택은 선택 사항이며 선택 시 결과 화면 설명 문구에 사용자 유형 반영

## 4. 화면 02: 계정 지표 입력

### 목적

플랫폼별로 필요한 계정 규모와 최근 콘텐츠 성과를 입력받는다.

### 데스크톱

```text
+--------------------------------------------------------------------------+
| CREATOR RATE                                      [1 / 3] 계정 지표      |
| [계정 지표] ================= [캠페인 조건] -------- [결과]              |
+--------------------------------------------------------------------------+
|                                                                          |
| 계정의 최근 성과를 입력해 주세요.                         ? 왜 필요한가요 |
|                                                                          |
| 플랫폼                                                                   |
| [Instagram v] [YouTube] [TikTok] [Blog]                                 |
|                                                                          |
| 계정명 또는 별칭 (선택)                                                  |
| [ 예: 민지의 뷰티 채널                         ]                        |
|                                                                          |
| 팔로워 수 *                                                              |
| [  125,000                                      ] 명                     |
|                                                                          |
| 최근 콘텐츠 평균 조회수/방문자 수 *                                      |
| [  48,000                                       ] 회                     |
|                                                                          |
| 최근 콘텐츠 평균 좋아요 수 *                                             |
| [  3,200                                        ] 개                     |
|                                                                          |
| 최근 콘텐츠 평균 댓글 수 *                                               |
| [  180                                          ] 개                     |
|                                                                          |
| 참여율 미리보기: 2.70%        조회 기반 참여율: 7.04%                    |
|                                                                          |
|                                         [다음: 캠페인 조건 ->]            |
+--------------------------------------------------------------------------+
```

### 모바일

```text
+------------------------------+
| [<]  계정 지표       1 / 3  |
| [========------------]       |
+------------------------------+
| 플랫폼                       |
| [Instagram              v]   |
|                              |
| 팔로워 수 *                  |
| [125,000             ] 명    |
|                              |
| 평균 조회수/방문자 수 *      |
| [48,000              ] 회    |
|                              |
| 평균 좋아요 수 *             |
| [3,200               ] 개    |
|                              |
| 평균 댓글 수 *               |
| [180                 ] 개    |
|                              |
| 참여율 2.70%                 |
|                              |
| [다음: 캠페인 조건 ->]       |
+------------------------------+
```

### 입력 상태

```text
정상       [125,000                         ] 명
오류       [0                                ] 명
           ! 팔로워 수는 1명 이상 입력해 주세요.
경고       [250,000                         ] 명
           ! 조회수가 팔로워 수보다 높습니다. 입력값을 확인해 주세요.
```

### 동작

- 플랫폼 변경 시 조회 지표의 단위와 도움말을 변경
- 숫자 입력 시 천 단위 구분 표시
- 필수값이 비어 있으면 다음 단계 이동 불가
- 경고값은 수정 권고를 표시하되 사용자가 확인하면 이동 가능
- 입력값은 새로고침 전까지 브라우저에 유지

## 5. 화면 03: 캠페인 조건

### 목적

콘텐츠 제작 범위와 광고 사용권을 입력해 단가 조정 요인을 반영한다.

### 데스크톱

```text
+--------------------------------------------------------------------------+
| CREATOR RATE                                    [2 / 3] 캠페인 조건      |
| 계정 지표 -------- [캠페인 조건] ================= [결과]                |
+--------------------------------------------------------------------------+
|                                                                          |
| 어떤 광고를 진행하나요?                                                  |
|                                                                          |
| 콘텐츠 형식 *                                                            |
| [피드 게시물] [숏폼/릴스] [유튜브 영상] [블로그 리뷰]                    |
|                                                                          |
| 게시물 수 *          [ 1 ]  -  +                                        |
| 제작 난이도          ( ) 기본   ( ) 높음   ( ) 전문 촬영                 |
|                                                                          |
| 추가 조건                                                                    |
| [ ] 광고주 계정 재게시                                                   |
| [ ] 유료 광고 집행을 위한 2차 사용권                                    |
|     사용 기간    [ 1개월 v ]                                             |
| [ ] 카테고리 독점                                                        |
|     독점 기간    [ 없음 v ]                                              |
|                                                                          |
| 수정 요청 횟수       [ 1 ]  -  +                                        |
| 희망 게시 일정       ( ) 일반 일정   ( ) 긴급 제작                       |
|                                                                          |
| [< 이전: 계정 지표]                         [단가 계산하기 ->]           |
+--------------------------------------------------------------------------+
```

### 모바일

```text
+------------------------------+
| [<] 캠페인 조건      2 / 3  |
| [================----]       |
+------------------------------+
| 콘텐츠 형식 *               |
| [피드 게시물             v]  |
|                              |
| 게시물 수                   |
| [-]       1       [+]        |
|                              |
| 제작 난이도                  |
| ( ) 기본  ( ) 높음           |
| ( ) 전문 촬영                |
|                              |
| 추가 조건                    |
| [ ] 광고주 계정 재게시       |
| [ ] 2차 사용권               |
| 사용 기간 [1개월          v] |
| [ ] 카테고리 독점            |
| 독점 기간 [없음            v]|
|                              |
| 수정 요청 [ - ] 1 [ + ]      |
|                              |
| [단가 계산하기 ->]           |
+------------------------------+
```

### 조건별 금액 변화 미리보기

선택한 조건이 있는 경우 우측 보조 영역에 다음처럼 표시한다.

```text
예상 조정 항목
+ 2차 사용권       + 150,000원
+ 카테고리 독점    + 200,000원
+ 전문 촬영        + 100,000원
```

## 6. 화면 04: 계산 결과

### 목적

### 데스크톱

```text

| 계정 지표 -------- 캠페인 조건 -------- [결과] =================          |

|                                                                          |
| 권장 제안가                                                             |
|                                                                          |
|                  1,350,000원 ~ 1,650,000원                              |
|                       참고용 예상 범위                                  |
|                                                                          |
| +--------------------------+  +----------------------------------------+ |
| | 예상 기본 단가           |  | 참여도 등급                           | |
| | 1,200,000원              |  | A  높음                               | |
| |                          |  | 팔로워 대비 반응이 높은 편입니다.    | |
| +--------------------------+  +----------------------------------------+ |
|                                                                          |
| 산정에 반영된 지표                                                       |
| 팔로워 125,000명 | 평균 조회 48,000회 | 참여율 2.70% | Instagram        |
|                                                                          |
| 금액을 올리는 요인                         금액에 반영된 추가 비용       |
```

## 7. 화면 05: 시나리오 비교

### 목적

최대 3개의 캠페인 조건을 나란히 비교해 협상 또는 예산 결정을 돕는다.

```text
+--------------------------------------------------------------------------+
| 시나리오 비교                                      [결과로 돌아가기]      |
+--------------------------------------------------------------------------+
| 조건                         A 기본       B 유료 집행      C 독점 포함    |
|                                                                          |
| 콘텐츠 형식                  피드         숏폼              숏폼          |
| 게시물 수                    1            1                 1             |
| 사용권                       없음         3개월             3개월         |
| 독점                         없음         없음              3개월         |
|                                                                          |
| 예상 기본 단가               1,200,000    1,300,000         1,300,000      |
| 추가 비용                    0            150,000            350,000       |
| 권장 제안가                  1.2~1.4M    1.45~1.7M          1.8~2.1M       |
|                                                                          |
| [A 조건 수정]                [B 조건 수정]                 [C 조건 수정]   |
|                                                                          |
|                         [이 결과 공유]                                  |
+--------------------------------------------------------------------------+
```

모바일에서는 시나리오를 가로 스크롤 가능한 표로 제공하고, 첫 번째 열의 조건명은 고정한다.

## 10. 반응형 기준

| 구간 | 레이아웃 | 주요 기준 |
| --- | --- | --- |
| 1200px 이상 | 2열 | 입력 영역 + 도움말/미리보기 |
| 768~1199px | 1열 중심 | 도움말은 입력 아래로 이동 |
| 767px 이하 | 모바일 단일열 | 하단 고정 액션, 결과 카드 세로 배치 |

- 하단 고정 액션은 입력 필드를 가리지 않도록 충분한 하단 여백을 확보한다.
- 결과 금액은 화면 폭에 맞춰 줄바꿈되며 다른 정보와 겹치지 않는다.
- 시나리오 비교 표는 모바일에서 가로 스크롤을 사용한다.
- 색상 외에도 등급 문자, 아이콘, 설명 문구로 상태를 전달한다.

## 11. 주요 상호작용 및 검증 포인트

1. 시작 화면에서 계산을 시작하면 화면 02에 진입한다.
2. 화면 02에서 필수 지표를 입력하면 참여율 미리보기가 즉시 갱신된다.
3. 비정상 입력은 오류 또는 경고로 구분된다.
4. 화면 03의 조건을 바꾸면 계산 결과의 기본 단가와 추가 비용이 달라진다.
5. 화면 04에서 계산 근거를 펼치고 접을 수 있다.
6. 화면 05에서 최대 3개 시나리오의 금액과 조건을 비교할 수 있다.
7. 공유 모달에서 원본 지표 숨김을 선택할 수 있다.
8. 모든 주요 화면에서 모바일 하단 액션으로 이전/다음 흐름을 완료할 수 있다.
